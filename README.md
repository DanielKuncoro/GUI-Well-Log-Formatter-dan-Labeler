# GUI Well Log Formatter dan Labeler
 
Aplikasi berbasis GUI untuk memformat dan melabeli data well log, dikembangkan sebagai bagian dari skripsi.
 
## Deskripsi
 
Tool ini memudahkan proses formatting dan pelabelan data well log secara interaktif melalui antarmuka grafis (GUI), sehingga mempercepat tahap preprocessing data dalam penelitian.
 
## Penggunaan
 
Aplikasi ini digunakan untuk keperluan penelitian skripsi dan tidak ditujukan untuk penggunaan produksi.
